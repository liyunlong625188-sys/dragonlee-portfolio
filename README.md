## 主要文件

- `index.html`：原始页面元数据、字体预加载和根节点；社交预览图片改为本地地址。
- `src/main.jsx`：加载原始应用，由原始应用自己挂载。
- `public/assets/`：原始运行时、Mercury 模块、样式、字体与作品媒体。文件名保留，以维持模块关联。
- `content/editable-content.json`：可读的姓名、简介、项目文字、项目链接与首页标签，供后续替换准备。
- `content/content-data.json`：完整项目、首页条目及媒体尺寸、裁切与响应式图片数据。
- `content/source-media-map.json`：逻辑作品图片名与本地媒体文件的映射。
- `content/capture-manifest.json`：源地址、文件路径与大小。
- `content/user-media.json`：用户替换媒体的来源、播放版本、尺寸与校验信息。

这些 JSON 记录原始内容与已完成的用户替换，渲染结果由同步更新的原始运行时提供。继续更换内容时需要保留项目 ID、媒体尺寸、srcsets 与交互关联，并记录运行时替换。当前未启用原站隐藏的编辑器或调试工具。
